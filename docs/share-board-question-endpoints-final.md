# Share Board Question Backend Endpoints Final

## 1. 범위

이 문서는 공유 보드 내 `질문 보드` 기능에 대한 백엔드 최종 엔드포인트만 정리한다.

전제:

- 공유 화면에는 `북마크 보드`와 `질문 보드`가 함께 존재한다.
- 질문은 `질문 보드`에 포스트잇 형태로 쌓인다.
- 질문 보드는 공유 보드 접근 권한이 있는 모든 사용자가 조회할 수 있다.

## 2. 리소스 정의

- `ShareBoard`: 공유 보드
- `ShareBoardQuestion`: 질문 보드에 쌓이는 질문 포스트잇

## 3. 최종 엔드포인트

### 3.1 질문 생성

`POST /api/v1/share-board/{shareBoardId}/questions`

목적:

- 공유 보드의 질문 보드에 새 질문 포스트잇을 생성한다.

인증:

- 필요

권한:

- 해당 공유 보드 접근 권한이 있는 사용자

비고:

- 질문 상태는 생성 시 `OPEN`

### 3.2 질문 보드 목록 조회

`GET /api/v1/share-board/{shareBoardId}/questions`

목적:

- 공유 보드의 질문 포스트잇 목록을 조회한다.

인증:

- 필요

권한:

- 해당 공유 보드 접근 권한이 있는 사용자

비고:

- 모든 방문자가 서로의 질문 포스트잇을 볼 수 있다.
- 기본 정렬은 최신순 권장
- 커서 기반 페이지네이션 권장

### 3.3 질문 수정

`PATCH /api/v1/share-board/question/{questionId}`

목적:

- 질문 작성자가 본인 질문 포스트잇의 내용을 수정한다.

인증:

- 필요

권한:

- 질문 작성자만 가능

제한:

- `USED` 상태 질문은 수정 불가

### 3.4 질문 삭제

`DELETE /api/v1/share-board/question/{questionId}`

목적:

- 질문 포스트잇을 삭제한다.

인증:

- 필요

권한:

- 질문 작성자
- 보드 주인

제한:

- `OPEN` 상태: 작성자 또는 보드 주인 삭제 가능
- `USED` 상태: 보드 주인만 삭제 가능

비고:

- 소프트 삭제 권장

### 3.5 질문 기반 인터뷰 시작

`POST /api/v1/share-board/question/{questionId}/start-interview`

목적:

- 보드 주인이 특정 질문 포스트잇을 선택해 새 인터뷰를 시작한다.

인증:

- 필요

권한:

- 보드 주인만 가능

후처리:

- 질문 상태를 `USED`로 변경
- `startedInterviewId` 연결
- 질문 포스트잇에 `인터뷰 진행됨` 표시 가능

## 4. 권한 매트릭스

| 기능 | 방문자 | 질문 작성자 | 보드 주인 |
|---|---|---|---|
| 질문 보드 조회 | 가능 | 가능 | 가능 |
| 질문 생성 | 가능 | 가능 | 가능 |
| 본인 질문 수정 | 불가 | 가능 | 작성자일 때만 가능 |
| `OPEN` 질문 삭제 | 불가 | 가능 | 가능 |
| `USED` 질문 삭제 | 불가 | 불가 | 가능 |
| 질문 기반 인터뷰 시작 | 불가 | 불가 | 가능 |

## 5. 상태 정의

- `OPEN`: 아직 인터뷰 시작에 사용되지 않은 질문
- `USED`: 인터뷰 시작에 사용된 질문
- `DELETED`: 삭제 처리된 질문

표시 라벨 예시:

- `OPEN` -> `대기 중`
- `USED` -> `인터뷰 진행됨`

## 6. 구현 권장사항

- 질문 목록 조회는 `shareBoardId + createdAt desc` 인덱스 기준으로 설계
- 삭제는 하드 삭제보다 소프트 삭제 권장
- `USED` 상태 변경은 인터뷰 생성 성공과 하나의 트랜잭션 또는 보상 로직으로 묶는 것이 안전
- 질문 수정/삭제 권한 검사는 서비스 레이어에서 명시적으로 분리

## 7. 제외한 엔드포인트

이번 최종안에서는 아래는 제외했다.

- 질문 단건 조회
- 질문 신고
- 질문 좋아요
- 질문 답글

MVP 범위에서는 목록 조회 중심으로 충분하다.
