# Share Board Question Feature Overview

## 1. 기능 목적

공유 보드를 본 사용자가 보드 주인에게 질문을 남길 수 있게 한다.

이 질문은 단순 댓글이 아니라, 보드 주인이 이후 인터뷰를 다시 시작할 때 사용할 수 있는 "인터뷰 시작 질문" 성격을 가진다.

즉 이 기능의 핵심 목적은 아래 두 가지다.

- 공유 보드를 매개로 사용자 간 상호작용을 만든다.
- 외부에서 받은 질문을 다음 인터뷰의 시작점으로 연결한다.

## 2. 사용자 역할

### 2.1 보드 주인

- 자신의 인터뷰에서 북마크한 질문-답변 쌍으로 공유 보드를 만든 사용자
- 다른 사용자가 남긴 질문을 확인할 수 있는 사용자
- 남겨진 질문을 기반으로 새 인터뷰를 시작할 수 있는 사용자

### 2.2 보드 방문자

- 공유 보드를 열람하는 사용자
- 보드 주인에게 질문을 남길 수 있는 사용자
- 자신이 남긴 질문만 수정/삭제할 수 있는 사용자

## 3. 기능 범위

이번 문서 범위는 "공유 보드 방문자가 보드 주인에게 질문을 남기는 기능"에 한정한다.

포함 범위:

- 질문 작성
- 질문 목록 조회
- 질문 수정
- 질문 삭제
- 보드 주인의 질문 확인
- 질문을 인터뷰 시작으로 연결하기 위한 최소 데이터 정의

제외 범위:

- 실제 인터뷰 생성 로직의 상세 구현
- 질문 기반 인터뷰 시작 화면 상세 UX
- 알림, 푸시, 이메일 발송
- 신고, 차단, 욕설 필터링 같은 운영 기능

## 4. 핵심 개념

### 4.1 북마크 보드

보드 주인이 인터뷰에서 북마크한 질문-답변 쌍을 포스트잇 형태로 구성한 공유용 보드다.

이 보드는 과거 인터뷰 내용을 보여주기 위한 보드다.

### 4.2 질문 보드

공유 보드를 본 방문자들이 보드 주인에게 남기는 질문 포스트잇 보드다.

이 보드는 미래 인터뷰를 시작하게 만드는 질문을 쌓는 보드다.
### 4.3 보드 질문

공유 보드를 본 사용자가 보드 주인에게 남기는 질문이다.

성격상 일반 댓글과 다르다.

- 대화형 댓글 스레드가 아니다.
- 보드 주인에게 전달하는 1차 질문이다.
- 이후 인터뷰 시작 프롬프트로 활용될 수 있다.

### 4.4 인터뷰 시작 질문

보드 질문 중 보드 주인이 선택한 질문이다.

선택된 질문은 새 인터뷰를 시작할 때 첫 질문 또는 시작 프롬프트로 전달될 수 있다.

## 5. 기본 정책 초안

- 로그인 사용자를 기준으로 동작한다.
- 보드 방문자는 공유 보드에 질문을 남길 수 있다.
- 질문 작성자는 본인 질문을 수정/삭제할 수 있다.
- 보드 주인도 자신의 질문 보드에 달린 질문을 삭제할 수 있다.
- 공유 보드 접근 권한이 있는 방문자는 질문 보드를 조회할 수 있다.
- 질문은 기본적으로 "공유 보드 단위"에 속한다.
- 질문은 북마크 보드와 분리된 "질문 보드"에 쌓인다.
- 질문이 인터뷰 시작에 사용된 뒤에는 보드 주인만 삭제할 수 있다.
- 사용된 질문 포스트잇에는 `인터뷰 진행됨` 상태를 표시한다.

## 7. 제안 용어

문서와 API에서는 아래 용어를 권장한다.

- Share Board: 공유 보드
- Bookmark Board: 인터뷰 북마크 포스트잇 보드
- Question Board: 방문자 질문 포스트잇 보드
- Board Memo: 포스트잇 형태의 북마크 카드
- Board Question: 방문자가 보드 주인에게 남기는 질문
- Interview Starter Question: 인터뷰 시작에 선택된 질문
