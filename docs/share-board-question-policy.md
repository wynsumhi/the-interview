# Share Board Question Policy

## 1. 기본 정책 초안

- 질문 작성은 로그인 사용자만 가능
- 질문 작성 대상은 공유 보드 내 질문 보드
- 질문 보드는 공유 보드 접근 권한이 있는 방문자 모두에게 공개됨
- 질문 작성자는 본인 질문만 수정 가능
- 질문 삭제는 질문 작성자 또는 보드 주인이 가능
- 보드 주인은 자신의 보드에 달린 질문 목록 조회 가능
- 질문은 이후 인터뷰 시작에 사용될 수 있음
- 공유 보드는 "북마크 보드"와 "질문 보드"의 2개 영역으로 구성됨
- 인터뷰 시작에 사용된 질문은 작성자가 더 이상 수정/삭제할 수 없음
- 인터뷰 시작에 사용된 질문은 보드 주인만 삭제 가능

## 2. 권한 정책

### 2.1 방문자

허용:

- 보드 열람 권한이 있는 경우 질문 작성
- 보드 열람 권한이 있는 경우 질문 보드 조회
- 자신이 작성한 질문 조회
- 자신이 작성한 질문 수정
- 자신이 작성한 질문 삭제

불가:

- 다른 사용자가 작성한 질문 수정/삭제
- 인터뷰 시작에 사용된 질문 수정
- 인터뷰 시작에 사용된 질문 삭제

### 2.2 보드 주인

허용:

- 자신의 보드에 달린 질문 목록 조회
- 자신의 질문 보드에 달린 질문 삭제
- 질문을 선택해 인터뷰 시작에 활용
- 인터뷰 시작에 사용된 질문 삭제

## 3. 접근 정책

질문 작성 및 질문 보드 조회 가능 여부는 공유 보드 접근 정책을 따른다.

예시:

- `PUBLIC`: 로그인 사용자는 질문 가능
- `FRIENDS`: 친구 관계 사용자만 질문 가능
- `PRIVATE`: 질문 불가 또는 소유자만 조회 가능

주의:

현재 저장소의 인터뷰 공개 범위 타입에는 `PUBLIC`, `PRIVATE`, `FRIENDS`가 존재한다. 공유 보드도 동일 정책을 재사용하는 것이 구현상 유리하다.

## 4. 유효성 정책 초안

- 질문 내용은 공백만 입력 불가
- 최소 길이: 1자 이상
- 최대 길이: 200자 또는 300자 중 기획 확정 필요
- 욕설/금칙어 필터는 현 단계 범위 제외

권장:

- MVP는 200자 제한으로 시작

## 5. 상태 정책 초안

질문 상태를 별도 관리하면 이후 기능 확장에 유리하다.

권장 상태:

- `OPEN`: 보드에 남겨졌고 아직 인터뷰 시작에 사용되지 않음
- `SELECTED`: 보드 주인이 인터뷰 시작용으로 선택함
- `USED`: 실제 인터뷰 생성에 사용됨
- `DELETED`: 삭제 처리됨

MVP에서 상태를 단순화하려면 아래처럼 시작할 수 있다.

- `ACTIVE`
- `DELETED`

다만 인터뷰 연결까지 고려하면 `USED` 상태는 초기에 넣는 편이 낫다.

## 6. 삭제 정책 초안

두 가지 방식이 가능하다.

### 6.1 소프트 삭제

- DB에 레코드를 남기고 삭제 상태만 변경
- 감사 추적과 인터뷰 연결 이력 관리에 유리

### 6.2 하드 삭제

- 실제 레코드 삭제
- 구현은 단순하지만 추적성이 떨어짐

권장:

- 소프트 삭제

## 7. 인터뷰 연결 정책 초안

질문이 인터뷰 시작에 사용되면 아래 중 하나를 저장한다.

- `startedInterviewId`
- `selectedAt`
- `usedAt`

기획 확인 필요:

- 사용된 질문은 작성자가 이후 수정/삭제할 수 없음
- 한 질문이 여러 인터뷰 시작에 재사용될 수 있는지

사용자 노출 정책:

- 질문 포스트잇에 `인터뷰 진행됨` 상태를 표시한다.
- 이 상태는 방문자도 볼 수 있어야 한다.
