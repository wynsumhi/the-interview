## 배포 방법

### 1. 소스 클론 및 브랜치 전환

```bash
git clone [REPOSITORY]
cd [REPOSITORY]
git switch develop
git pull origin develop
```

### 2. 환경 변수 파일 생성

```bash
# 인프라 환경 변수 (.env.example 참고하여 작성)
cp infra/.env.example infra/.env
vi infra/.env

# 프론트엔드 환경 변수
cp fe/.env.template fe/.env
vi fe/.env

# AI 서비스 환경 변수
cp ai/.env.example ai/.env
vi ai/.env
```

### 3. Docker 네트워크 생성

```bash
cd infra
chmod +x network/setup-network.sh
./network/setup-network.sh
```

- `theinterview-net` 외부 네트워크가 생성됨
- 모든 컨테이너가 이 네트워크를 통해 통신

### 4. 데이터베이스 계층 실행

```bash
docker compose -f database/db-compose.yml up -d
```

- PostgreSQL 16 (pgvector 확장 포함) + Redis 가동
- 헬스체크 통과 확인:
    ```bash
    docker compose -f database/db-compose.yml ps
    ```

### 5. 초기 데이터 입력

```bash
# DB 덤프 파일 적용
docker exec -i postgres-db psql -U [DB_USER] -d [DB_NAME] < ../exec/db_dump.sql
```

- **반드시 덤프 파일을 적용한 후 애플리케이션을 빌드해야 합니다.**
- 덤프 파일을 적용하지 않으면 백엔드 서버가 정상 실행되지 않습니다.

### 6. 관리 도구 및 프록시 서버 실행

```bash
docker compose -f management/management-compose.yml up -d
```

- Nginx (리버스 프록시, SSL 종료)
- Jenkins (CI/CD)
- Bridge Server (GitLab 웹훅 → Mattermost 알림)

### 7. 모니터링 계층 실행

```bash
docker compose -f monitoring/monitoring-compose.yml up -d
```

- Prometheus, Grafana, Loki, Promtail, Node Exporter, cAdvisor

### 8. 애플리케이션 계층 실행

```bash
docker compose -f app/app-compose.yml up -d
```

- Backend (Spring Boot) + Frontend (Next.js) 가동

### 9. AI 서비스 실행 (GPU 서버)

```bash
cd ../ai
docker compose up -d
```

- FastAPI + vLLM 임베딩 서버 + Qdrant 가동
- **GPU(CUDA) 지원이 필요합니다**

### 10. 전체 서비스 상태 확인

```bash
docker ps -a
```

### 일괄 배포/종료 스크립트

```bash
# 전체 배포 (infra 디렉토리에서 실행)
cd infra
chmod +x self-deploy-all.sh
./self-deploy-all.sh

# 전체 종료
chmod +x self-undeploy-all.sh
./self-undeploy-all.sh
```

## 배포 시 특이사항

### SSL 인증서 경로

- 호스트 OS의 `/etc/letsencrypt` 경로에 SSL 인증서가 존재해야 Nginx가 정상 동작합니다.
- 도메인: `j14a307.p.ssafy.io`

### Docker 네트워크

- `theinterview-net` 외부 네트워크가 반드시 먼저 생성되어야 합니다.
- `./infra/network/setup-network.sh` 스크립트로 자동 생성 가능

### AI 서비스 (GPU 필수)

- AI 서비스는 NVIDIA GPU가 장착된 별도 서버에서 실행합니다.
- CUDA 12.4.1 이상, Docker GPU 런타임 설정 필요
- Nginx에서 `/api/v1/ai` 경로를 외부 AI 서버로 프록시합니다.

### 데이터 입력 순서

- DB 덤프 파일을 적용하지 않으면 백엔드 서버는 실행되지 않습니다.
- 반드시 덤프 파일의 데이터를 적용시킨 후 애플리케이션 빌드를 진행해야 합니다.

### 의존성 순서

- 네트워크 → DB/Redis → 관리도구(Nginx, Jenkins) → 모니터링 → 애플리케이션(BE, FE) → AI 서비스
